# Тарифный план JavaScript 2024

## Информация о тарифном плане курса

Этот репозиторий содержит материалы курса JavaScript 2024 от itgid.info.

### Текущий тарифный план

**Тариф:** Базовый  
**Статус:** Активен  
**Доступ:** Полный доступ к курсу JavaScript 2024

### Что включено в тарифный план:

- ✓ Доступ ко всем спринтам курса (sprint_01 - sprint_15)
- ✓ Теоретические материалы (theory/)
- ✓ Практические задания
- ✓ Примеры кода и решения

### Как проверить свой тарифный план

1. Откройте файл `tariff-plan.html` в браузере
2. Нажмите кнопку "Проверить тарифный план"
3. Просмотрите информацию о вашем текущем тарифе

### Структура курса

Курс разделен на спринты:
- Sprint 01-15: Основные темы JavaScript
- Theory: Теоретические материалы и примеры

Для получения более подробной информации о тарифах посетите: https://itgid.info
